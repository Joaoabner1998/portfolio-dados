# 📊 Portfólio de Projetos | João Abner

Bem-vindo ao meu portfólio!

Sou estudante de **Análise e Desenvolvimento de Sistemas (ADS)**, com interesse em análise de dados, desenvolvimento de sistemas e soluções tecnológicas.

Neste repositório apresento projetos acadêmicos e práticos desenvolvidos para aprimorar minhas competências em programação, bancos de dados, análise de informações e visualização de dados.

## 🛠️ Tecnologias e ferramentas

- **Python:** manipulação e análise de dados
- **Pandas:** tratamento e exploração de dados
- **SQL e PostgreSQL:** modelagem, consultas e gerenciamento de bancos de dados
- **Power BI:** criação de dashboards e indicadores
- **Git e GitHub:** versionamento e documentação de projetos
- **Scrum:** organização e planejamento ágil de projetos

## 🚀 Projetos

### 01 — Python e Pandas
Exercícios e análises práticas utilizando Python e a biblioteca Pandas para manipular, organizar e explorar conjuntos de dados.

### 02 — Análise de Vendas
Projeto voltado à análise de dados comerciais, explorando informações de vendas para apoiar a interpretação de indicadores.

### 03 — Loja de Rodas Sustentável
Projeto de análise de dados aplicado a uma loja fictícia de rodas, com foco em desempenho comercial e sustentabilidade.

**Tecnologias:** Python, PostgreSQL, SQL e Power BI.

**Atividades desenvolvidas:**
- Estruturação de tabelas de vendas, resíduos e fornecedores.
- Consultas SQL para análise dos dados.
- Construção de indicadores de faturamento, ticket médio e reciclagem.
- Desenvolvimento de dashboard no Power BI.

### 04 — People Analytics
Projeto de análise de dados de recursos humanos utilizando uma base de funcionários para estudar indicadores organizacionais.

**Tecnologias:** Python, SQL e Power BI.

**Atividades desenvolvidas:**
- Análise de funcionários ativos e desligados.
- Cálculo de salários médios por departamento.
- Análise de avaliações de desempenho.
- Construção de indicadores e visualizações de RH.
