# 📊 Portfólio de Análise de Dados

Olá! Este repositório reúne meus projetos e estudos na área de Análise de Dados.

Estou desenvolvendo projetos práticos utilizando Python, Pandas, SQL, Excel e Power BI, aplicando técnicas de análise, tratamento e visualização de dados.

## 🛠️ Tecnologias

- Python
- Pandas
- SQL
- Excel
- Power BI
- Matplotlib
- Git
- GitHub

## 📂 Projetos

### 01 - Python e Pandas

Projeto introdutório para aprendizado de manipulação e análise de dados utilizando Python e Pandas.

Principais conceitos utilizados:

- leitura de arquivos CSV;
- criação de DataFrames;
- filtros;
- ordenação;
- criação de colunas;
- cálculos de faturamento;
- análise de produtos.

---

### 02 - Análise de Vendas

Análise de uma base de vendas utilizando Python, Pandas e Matplotlib.

Foram analisados indicadores como:

- faturamento total;
- quantidade de produtos vendidos;
- ticket médio;
- faturamento por categoria;
- faturamento por cidade;
- faturamento por mês;
- produtos com maior faturamento;
- formas de pagamento.

Também foram desenvolvidas visualizações gráficas para apresentação dos resultados.

## 🎯 Objetivo

Este portfólio tem como objetivo demonstrar minha evolução e meus conhecimentos práticos em análise de dados através de projetos desenvolvidos durante meus estudos.
