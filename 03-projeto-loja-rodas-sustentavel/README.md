
### 03 — Loja Guga Rodas Sustentável

Projeto de análise de dados desenvolvido para avaliar o desempenho comercial e os indicadores de sustentabilidade da Loja Guga Rodas.

**Tecnologias utilizadas:** Python, PostgreSQL, SQL e Power BI.

**Principais atividades:**
- Organização e análise de dados de vendas, resíduos e fornecedores.
- Desenvolvimento de consultas SQL para análise das informações.
- Criação de indicadores de faturamento total, quantidade vendida e ticket médio.
- Análise da taxa de reciclagem e do valor recuperado.
- Desenvolvimento de dashboard interativo no Power BI.
- Visualização de dados para apoiar decisões comerciais e práticas sustentáveis.

**Objetivo do projeto:**

Demonstrar como a análise de dados pode contribuir para melhorar a gestão comercial, acompanhar indicadores de sustentabilidade e apoiar a tomada de decisões.
